# Aletheia iOS (старт миграции)

Это каркас iOS-версии на Kotlin Multiplatform + Compose Multiplatform.
Android-проект остаётся как есть, эта папка лежит рядом (или в том же репозитории).

## Что внутри
- `shared/` — общий Kotlin-код и интерфейс на Compose. В `commonMain` уже перенесены 13 файлов
  чистой логики из Android-версии без изменений (разбор «артист — название», ссылки плейлистов,
  имена файлов, DSP-стили, A–B loop, расписание тем, время солнца и др.).
- `iosApp/` — оболочка SwiftUI. Xcode-проект создаётся автоматически из `iosApp/project.yml` через XcodeGen.
- `.github/workflows/ios.yml` — сборка на macOS в облаке GitHub (Mac не нужен).
- `MIGRATION.md` — что осталось перенести и чем заменить.

## Как собрать без Mac
1. Создайте репозиторий на GitHub (можно приватный) и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions**, выберите **iOS build** и нажмите **Run workflow**.
3. Если сборка упала, откройте лог шага, скопируйте ошибку и пришлите мне — я исправлю.

Эта сборка проверяет, что приложение компилируется для iOS Simulator. Чтобы поставить его на реальный
iPhone, нужна подпись: бесплатный Apple ID (7 дней) или Apple Developer (99 $/год).
Подпись настраивается в CI отдельно (Codemagic делает это проще всего).

## Важно
Каркас написан без возможности его собрать (в среде, где он создавался, нет Gradle и macOS),
поэтому первая сборка может показать ошибки версий или импортов — это ожидаемо.
